Generate Frontend for SkillDzire Online Compiler

Build a modern, production-ready, responsive frontend for an Online Code Compiler & Mini IDE called "SkillDzire CodeLab". The compiler is part of the SkillDzire learning ecosystem, so the design should match the official SkillDzire website branding and colors.

🌐 Backend Integration (Very Important)

Design the frontend around these existing backend APIs.

Health Check
GET /api/health
Projects
POST   /api/projects
GET    /api/projects
GET    /api/projects/:id
PUT    /api/projects/:id
DELETE /api/projects/:id

Project object:

{
  _id: string;
  title: string;
  language: string;
  currentCode: string;
  createdAt: string;
}
Versions
POST /api/versions/:projectId
GET  /api/versions/:projectId
GET  /api/versions/single/:versionId
POST /api/projects/:projectId/restore/:versionId

Version object:

{
  _id: string;
  projectId: string;
  versionNumber: number;
  code: string;
  createdAt: string;
}
Execute Code
Endpoint
POST /api/execute
Request
{
  "language": "python",
  "code": "print('Hello')",
  "stdin": ""
}
Response
{
  "success": true,
  "jobId": "...",
  "language": "python",
  "stdout": "Hello\n",
  "stderr": "",
  "executionTime": 1150,
  "status": "completed"
}

Possible status values:

completed
runtime_error
compile_error
timeout
Execution History
GET /api/executions
GET /api/executions/:jobId
GET /api/executions/project/:projectId
GET /api/executions/user/:userId

Execution History object:

{
  _id: string;
  jobId: string;
  language: string;
  code: string;
  stdin: string;
  stdout: string;
  stderr: string;
  executionTime: number;
  status: string;
  createdAt: string;
}

The frontend should already map directly to these APIs without requiring backend changes.

🚫 Authentication

Do NOT generate login, signup, JWT, Google OAuth, or authentication pages. This compiler will later be embedded into the SkillDzire LMS and authentication will be handled externally.

🎯 Goal

Generate a fully functional, responsive, component-based frontend folder that can connect to the existing backend with little or no modification. Focus on maintainability, clean architecture, API compatibility, and a polished educational developer experience that feels like an official SkillDzire product rather than a generic online compiler.
